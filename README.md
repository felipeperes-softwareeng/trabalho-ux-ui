# Trabalho UX/UI: Redesign do EduConnect

Atividade de Redesign da disciplina Design de Experiência do Usuário (UX) e Interfaces (UI), UniAnchieta.

Redesign completo da interface do portal acadêmico EduConnect: visual premium, layout responsivo (computador, tablet e celular), modo claro e escuro, logo 3D e foco em acessibilidade.

## Conteúdo
- `educonnect-premium/`: código-fonte do site (React 18, TypeScript, Vite, Tailwind). Veja o README da pasta para executar.
- `documento/`: documento com a análise do site original, os problemas identificados e as justificativas de cada mudança (PDF e HTML).
- `logo/`: logo do EduConnect (SVG e PNG).

## Executar
```bash
cd educonnect-premium
npm install
npm run dev
```
